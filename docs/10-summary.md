# 10. 한눈에 보는 정리

**BookBot** — 대화로 책을 찾아주는 AWS 서버리스 챗봇
`Un Livre Pour Vous · CHOWOO` · <https://CLOUDFRONT_DOMAIN_MASKED.cloudfront.net>

---

## 한 문단 요약

"요즘 지쳤는데 위로되는 소설" 처럼 **기분으로 물어도 책을 찾아주는** 서비스입니다.
Claude 가 질문을 읽고 필요한 검색 도구를 스스로 골라 도서 API 5종을 동시에 조회하고,
같은 책을 ISBN-13 으로 합쳐서 표지·평점·무드·무료 전문 링크가 붙은 카드로 보여줍니다.
서버는 전부 서버리스라 **쓰지 않으면 요금이 0** 이고, 2주 운영 예상 비용은 3만 원 안팎입니다.

## 흐름 한 장

```
사용자
  │  "요즘 지쳤는데 위로되는 한국 소설"
  ▼
CloudFront ──────────────► S3 (React 정적 파일, 완전 비공개)
  │  /api/*
  ▼
API Gateway ─► Lambda (Node 22 · arm64)
                │
                ├─ ① 정책 검사   규칙 + LLM 2단
                ├─ ② 세션 로드   DynamoDB
                ├─ ③ Bedrock     Claude Sonnet 4.6 + 도구 4종
                │      │
                │      └─► 도서 API 5종 병렬 호출
                │            Google Books · Open Library · Hardcover
                │            Gutendex · 알라딘(한글일 때)
                │              │
                │              └─ ISBN-13 조인 → 중복 제거 → 정렬
                │                   ├─ 원본 카드 ──► 프론트 (표지·평점·링크)
                │                   └─ 압축 요약 ──► LLM (토큰 99% 절감)
                ├─ ④ 기록 저장   DynamoDB (90일 TTL) → logRef 반환
                └─ ⑤ 응답        답변 + 책 카드 + logRef
                       │
                       ▼
                  사용자가 저장·평가
```

## 기술 선택 요약

| 영역 | 선택 | 이유 |
|---|---|---|
| 컴퓨팅 | Lambda (arm64) | 트래픽 없으면 0원. arm64 가 20% 저렴 |
| 데이터 | DynamoDB 단일 테이블 | 항목 4종을 pk 접두사로 구분. 관리 지점 하나 |
| LLM | Bedrock Claude Sonnet 4.6 | 도구 호출 + 스트리밍. 키 관리 불필요(IAM) |
| 비밀값 | SSM Parameter Store | SecureString. 경로 와일드카드라 키 추가 시 IAM 수정 불필요 |
| 배포 | S3 + CloudFront | 단일 도메인이라 CORS 없음 |
| API | API Gateway HTTP API | 함수 URL 이 계정 정책으로 막혀 전환 |
| 프론트 | React 18 + Vite | 번들 57.8kB (gzip) |
| 상태관리 | `useSyncExternalStore` | Provider 없이 모듈 하나로 공유 |
| 저장 | localStorage | 로그인 없이 "같은 브라우저에서는 남는다" |

## 눈에 띄는 설계 3가지

### 1. 이중 채널 — 토큰 99% 절감

도서 API 응답은 한 번에 6만 자가 넘습니다. 이걸 그대로 LLM 에 넣으면 비용이 폭발합니다.
그래서 **같은 데이터를 두 갈래로 나눕니다.**

- **프론트** ← 원본 레코드 (표지 URL·평점·무드·다운로드 링크)
- **LLM** ← 제목·저자·연도만 남긴 압축본 (61,780자 → 779자)

카드에 보이는 값이 전부 실제 API 데이터라 **환각이 원천적으로 불가능**하고,
동시에 토큰은 100분의 1로 줍니다.

### 2. ISBN-13 조인 — 같은 책을 하나로

6개 소스가 같은 책을 다르게 표현합니다. ISBN-10/13 을 정규화해 조인하고,
ISBN 이 없으면 제목+저자를 정규화해 비교합니다. 필드별로 **어느 소스를 믿을지**
우선순위를 따로 둡니다 — 표지는 Google Books, 무드는 Hardcover, 국내서 표지는 알라딘.

### 3. 2단 정책 검사 — 도서관의 기준

규칙 기반으로 프롬프트 인젝션·개인정보·유해 요청을 먼저 걸러내고, 애매한 것만
LLM 판정으로 넘깁니다. 성인 문학은 **허용**합니다(도서관은 주제로 검열하지 않습니다).
단 미성년 관련은 예외 없는 절대 차단선(`MINOR_SAFETY`)을 둡니다.

## 검증 체계

배포 전에 한 번에 돌립니다. **`smoke` 만 네트워크를 쓰고 나머지는 결과가 흔들리지 않습니다.**

```bash
cd backend
npm run check          # 문법
npm run test:policy    # 36건  정책·가드레일
npm run test:agent     # 18건  도구 루프
npm run test:features  # 46건  평가·알라딘·logRef 보안
npm run smoke          # 14건  외부 API 실호출

cd ../frontend
npm run test:saved     # 30건  읽을 목록 저장소
npm run check:render   # 22건  화면 렌더 (브라우저 없이)
npm run build
```

합계 **166건**. `verify.sh` 는 배포 후 실제 사이트를 호출해 채팅·평가·보안·
레이트리밋까지 확인합니다.

## 배포

CloudShell(us-east-1)에 zip 을 업로드한 뒤 **한 줄**만 붙여넣습니다.

```bash
cd ~ && rm -rf bookbot && unzip -oq bookbot-cloudshell.zip -d bookbot && cd bookbot && bash infra/oneshot.sh
```

`oneshot.sh` 가 Node 확인 → 비밀값 복원 → 백엔드·프론트 배포 → 캐시 무효화 →
가드레일 → 검증 → 키 로드 확인까지 순서대로 합니다.
비밀값은 `~/keep/secrets.env` 에 있어 압축을 다시 풀어도 사라지지 않습니다.

단계를 나누고 싶으면 `update.sh` · `04-guardrails.sh` · `verify.sh` 를 따로 실행하면 됩니다.

자세한 절차는 [06-deploy-now.md](./06-deploy-now.md), 운영은
[05-runbook.md](./05-runbook.md) 를 보세요.
