```
# 답변 형식               기본은 짧은 목록
# 답변은 질문에 맞아야     조건 하나하나 확인
# 대화 스타일 / 답변 길이
# 검색어 언어             품질에 직결
```

### 검증

```bash
cd backend && node scripts/check.mjs   # 프롬프트 5개 절 표지가 살아있는지
node scripts/policy-test.mjs           # 정책 99건
```

`check.mjs`가 절 표지를 세는 이유: 프롬프트가 잘려도 문법 오류가 안 나서
테스트 없이는 조용히 망가집니다.
